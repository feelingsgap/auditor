정답: ③ (3번)

해설:
가상 페이지 수는 `4GB / 4KB = 2^32 / 2^12 = 2^20`개이다. 단층 페이지 테이블에는 페이지마다 엔트리 하나가 필요하므로 전체 크기는 다음과 같다.

`2^20 × 4B = 2^22B = 4MB`

각 보기 분석:
① 4KB는 페이지 한 개의 크기일 뿐 전체 테이블 크기가 아니다.
② 1MB는 엔트리 수 또는 바이트 환산을 잘못한 값이다.
③ `2^20`개 엔트리 각각 4바이트이므로 4MB가 맞다.
④ 16MB는 페이지 수에 엔트리 크기를 과다 적용한 값이다.

시험 포인트:
4GB와 4KB의 단위를 먼저 2의 거듭제곱으로 통일한다. 페이지 오프셋 12비트를 제외한 20비트가 가상 페이지 번호이므로 엔트리는 `2^20`개다.

핵심 정리:
단층 페이지 테이블 크기 = 가상 주소 공간의 페이지 수 × 페이지 테이블 엔트리 크기.
