정답: ④ (4번)

해설:
A는 학습 데이터나 라벨을 조작해 학습 자체를 왜곡하므로 Data Poisoning Attack이다. B는 추론 입력에 미세한 교란을 가해 오분류를 유도하므로 Adversarial Attack이다. 따라서 A-ㄷ, B-ㄹ이다.

각 보기 분석:
ㄱ. Model Extraction — 반복 질의와 출력 관찰로 대상 모델의 의사결정 기능이나 대체 모델을 복제하려는 공격이다.
ㄴ. Model Inversion — 모델 출력·기울기 등에서 학습 데이터의 민감 특성이나 대표 입력을 추론하려는 공격이다.
ㄷ. Data Poisoning — 조작 샘플이나 잘못된 라벨을 학습 데이터에 넣어 모델의 전체 성능을 떨어뜨리거나 특정 트리거에서 오작동하게 한다. A다.
ㄹ. Adversarial Attack — 학습된 모델의 입력에 작은 교란을 넣어 분류 경계를 넘기고 오예측을 유도한다. B다.
①은 A를 추론 입력 공격, B를 모델 역전으로 잘못 연결한다. ②는 두 사례를 모델 역전·추출과 혼동했다. ③은 A를 모델 추출, B를 포이즈닝으로 잘못 연결한다. ④만 A-데이터 포이즈닝, B-적대적 공격을 정확히 연결한다.

시험 포인트:
A-ㄷ, B-ㄹ을 연결한 ④가 정답이다. 가장 먼저 공격 시점을 본다. 학습 전·중 데이터셋을 오염시키면 포이즈닝, 배포된 모델에 교란 입력을 주면 적대적 공격이다. 추출과 역전은 각각 모델 기능 탈취와 학습정보 추론이라는 목표가 다르다.

핵심 정리:
데이터 포이즈닝은 학습 단계, 적대적 예제 공격은 주로 추론 단계의 입력을 공격한다.
