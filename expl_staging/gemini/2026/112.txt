정답: ① (1번)

해설:
클라우드 환경에서 API 키가 public 코드 저장소 등에 노출되었을 때 즉시 수행해야 하는 차단 대응 조치를 묻는 문제입니다.

상세 분석:
* **① (정답):** 노출된 API 키는 악의적 제3자에 의해 이미 수집되어 도용될 수 있으므로, 즉시 해당 키를 폐기(Revoke)하여 권한을 무효화하고 새로운 키를 발급(Rotate)하는 것이 최우선 과제입니다.
* **② (오답):** 코드 저장소 접근 권한만 제한하더라도 이미 유출된 API 키 자체의 인프라 접근 권한은 남아있으므로 근본적 해결이 되지 않습니다.
* **③ (오답):** 만료 기간이 존재하더라도 만료 전까지 무단 사용으로 인한 무단 자원 생성, 데이터 유출 등의 심각한 피해가 발생하므로 방치해서는 안 됩니다.
* **④ (오답):** 이미 외부에 평문으로 노출된 키를 코드상에서 암호화하더라도 유출된 키의 유효성은 유지되므로 무의미합니다.

📌 학습 포인트:
* 자격증명 유출 발생 시 최우선 조치: 유출된 키 즉시 폐기(Revoke) -> 신규 키 재발급(Rotate) -> 유출 경로 감사 및 시정.
