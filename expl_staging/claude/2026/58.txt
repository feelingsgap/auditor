정답: ② (2번)

해설:
DBMS의 3대 기능인 데이터 정의(DDL), 데이터 조작(DML), 데이터 제어(DCL)와 각 기능에 대응하는 SQL 문의 분류를 묻는 문항이다. 특히 TRUNCATE의 소속과 저장 구조 정의 기능의 소속이 함정이다.

각 보기 분석:
가. 데이터 정의 기능은 스키마를 정의하며 CREATE, ALTER, DROP으로 수행된다 — DDL의 정확한 정의다. 테이블, 뷰, 인덱스 등 스키마 객체의 생성·변경·삭제가 여기에 속한다. 옳다.
나. 데이터 조작 기능에 SELECT, INSERT, UPDATE, TRUNCATE가 포함된다 — TRUNCATE는 테이블 구조는 남기고 데이터를 일괄 제거하는 DDL로 분류되며, 자동 커밋되어 롤백이 어렵고 행 단위 로그를 남기지 않는다. DML의 삭제문은 DELETE이므로 이 보기는 틀렸다.
다. 데이터 제어 기능은 사용자 권한을 관리하며 GRANT, REVOKE가 포함된다 — DCL의 정확한 정의다. 권한 부여와 회수를 담당한다. 옳다.
라. 데이터 조작 기능은 저장 구조를 정의하는 기능이며 CREATE TABLE로 수행된다 — 저장 구조와 스키마 정의는 데이터 조작이 아니라 데이터 정의 기능이며, CREATE TABLE도 DDL이다. 기능 이름과 문장이 모두 어긋나 틀렸다.

따라서 옳은 것은 가와 다이므로 ② 가, 다가 정답이다.
① 가, 나 — 나가 TRUNCATE 때문에 틀렸다.
② 가, 다 — 옳은 보기만 정확히 묶었다. 정답.
③ 가, 나, 다 — 나가 포함되어 틀렸다.
④ 나, 다, 라 — 나와 라 두 개가 틀렸다.

핵심 정리:
DDL: CREATE, ALTER, DROP, TRUNCATE, RENAME(스키마 정의·변경, 대개 자동 커밋).
DML: SELECT, INSERT, UPDATE, DELETE(데이터 검색·삽입·수정·삭제, 트랜잭션 제어 대상).
DCL: GRANT, REVOKE(권한 관리). TCL로 별도 분류하면 COMMIT, ROLLBACK, SAVEPOINT가 여기에 해당한다.
DELETE와 TRUNCATE의 구분이 단골 함정이다. DELETE는 DML로 WHERE 조건과 롤백이 가능하고, TRUNCATE는 DDL로 전체 삭제만 가능하며 되돌리기 어렵다.
