정답: ④ (4번)

해설:
AI·머신러닝 모델에 대한 보안 공격을 공격이 일어나는 생명주기 단계로 구분하는 문항이다. 학습 단계(training phase)를 오염시키는 공격과 추론 단계(inference phase)에서 입력을 미세 조작하는 공격을 구분하는 것이 핵심이다.

각 항목 판정:
ㄱ. Model Extraction Attack — 대상 모델에 반복 질의하여 응답을 수집하고 유사 성능의 대체 모델을 복제해 내는 공격으로, 모델 자체(지식재산)를 탈취하는 것이 목적이다. 두 설명에 해당하지 않는다.
ㄴ. Model Inversion Attack — 모델의 출력이나 신뢰도 값을 역으로 이용해 학습에 사용된 원본 데이터(예: 얼굴 이미지, 개인정보)를 복원해 내는 프라이버시 침해 공격이다. 두 설명에 해당하지 않는다.
ㄷ. Data Poisoning Attack — 학습 데이터셋에 조작된 데이터나 잘못된 라벨을 주입하여 모델이 왜곡된 패턴을 학습하게 만드는 공격이다. 설명 A(학습 단계 왜곡, 성능 저하 또는 특정 오분류 유도)와 일치한다.
ㄹ. Adversarial Attack — 학습이 끝난 모델의 추론 단계에서 사람 눈에 띄지 않는 미세한 섭동(perturbation)을 입력에 더해 분류 경계를 넘기고 오분류를 유발하는 공격이다. 설명 B와 일치한다.

각 보기 분석:
① A-ㄹ, B-ㄴ — A는 추론 단계 공격이 아니라 학습 데이터 오염이므로 틀리다.
② A-ㄴ, B-ㄱ — 프라이버시 복원 공격과 모델 복제 공격을 잘못 대응시켰다.
③ A-ㄱ, B-ㄷ — 학습 단계와 추론 단계를 서로 뒤바꾼 짝짓기다.
④ A-ㄷ, B-ㄹ — 학습 단계 오염은 Data Poisoning, 추론 단계 섭동은 Adversarial Attack이다. 정답.

핵심 정리:
단계별 구분: 학습 단계 공격은 Data Poisoning(백도어·트로이 목마 삽입 포함), 추론 단계 공격은 Adversarial Example(FGSM, PGD 등)이다.
프라이버시 계열: Model Inversion(학습 데이터 복원), Membership Inference(특정 데이터의 학습 포함 여부 추론).
자산 탈취 계열: Model Extraction/Stealing(질의 응답으로 모델 복제).
대응: 학습 데이터 출처 검증과 이상 탐지, 적대적 학습(adversarial training), 질의 속도 제한과 출력 신뢰도 라운딩, 차분 프라이버시.
