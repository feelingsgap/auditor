정답: ④ (4번)

해설:
Y = A + AB' + A'B 논리식을 불 대수(Boolean Algebra) 정리로 간략화하는 문항이다. 흡수 법칙(Absorption Law)과 보수 흡수 법칙을 순서대로 적용하면 된다.

간략화 과정:
1단계 — 흡수 법칙 적용: A + AB' = A(1 + B') = A · 1 = A
  따라서 Y = A + AB' + A'B = A + A'B
2단계 — 보수 흡수 법칙(A + A'B = A + B) 적용:
  A + A'B = (A + A')(A + B) = 1 · (A + B) = A + B
3단계 — 최종 결과: Y = A + B

진리표 검증:
A=0, B=0 → 0 + 0·1 + 1·0 = 0 (A+B = 0 일치)
A=0, B=1 → 0 + 0·0 + 1·1 = 1 (A+B = 1 일치)
A=1, B=0 → 1 + 1·1 + 0·0 = 1 (A+B = 1 일치)
A=1, B=1 → 1 + 1·0 + 0·1 = 1 (A+B = 1 일치)
네 경우 모두 A + B와 동일하므로 간략화가 정확하다.

각 보기 분석:
① Y = AB' — 원식의 두 번째 항만 남긴 형태다. A=1, B=1일 때 원식은 1이지만 AB'는 0이 되어 불일치하므로 오답.
② Y = AB — A=1, B=0일 때 원식은 1인데 AB는 0이 되어 불일치하므로 오답.
③ Y = A' + B — A=1, B=0일 때 원식은 1인데 A'+B = 0+0 = 0이 되어 불일치하므로 오답. A+B와 A'+B를 혼동하기 쉬운 함정 보기다.
④ Y = A + B — 흡수 법칙과 보수 흡수 법칙을 적용한 결과이며 진리표가 원식과 완전히 일치한다. 정답.

핵심 정리:
흡수 법칙: A + AB = A, A(A + B) = A. 항 하나가 다른 항을 포함하면 큰 쪽이 흡수된다.
보수 흡수 법칙: A + A'B = A + B, A(A' + B) = AB. 보수가 붙은 변수는 사라진다는 점이 포인트다.
카르노맵으로 확인하면 A + AB' + A'B는 AB=00을 제외한 세 칸(01, 10, 11)이 1이므로, A 행 전체와 B 열 전체를 묶어 A + B가 된다.
함정 포인트는 2단계에서 A + A'B를 A'B로 잘못 축약하거나 A' + B로 부호를 뒤집는 것이다. 결과에 보수 기호가 남았다면 대부분 오류이니 진리표로 한 번 검산하는 습관이 안전하다.
