정답: ④ (4번)

해설:
로버트 마틴이 제시한 패키지 결합도 지표인 비안정성(Instability) I를 계산하는 문항이다.
I = Ce / (Ca + Ce)
Ce(원심 결합도, Efferent Coupling)는 패키지 내부 클래스가 외부 클래스에 의존하는 관계의 수, Ca(구심 결합도, Afferent Coupling)는 외부 클래스가 패키지 내부 클래스에 의존하는 관계의 수이다.

그림에서 읽은 의존 관계:
Package A에는 C1, C2가, Package B에는 C3, C4가, Package C에는 C5, C6가 들어 있다.
C2 → C3 (A에서 B로 나가는 의존) : Package A의 Ce에 해당하며 1개이다.
C4 → C2 (B에서 A로 들어오는 의존)
C6 → C2 (C에서 A로 들어오는 의존)
C5 → C1 (C에서 A로 들어오는 의존)
즉 Package A로 들어오는 화살표는 3개이므로 Ca = 3, 나가는 화살표는 1개이므로 Ce = 1이다.

계산:
I = Ce / (Ca + Ce) = 1 / (3 + 1) = 1/4

각 보기 분석:
① Instability = 0 — Ce가 0일 때, 즉 나가는 의존이 전혀 없는 완전히 안정적인 패키지의 값이다. C2에서 C3로 나가는 의존이 있으므로 0이 아니다.
② Instability = 1/2 — Ca와 Ce가 같을 때(예: 1과 1)의 값으로, 들어오는 의존을 1개만 세었을 때 나오는 오답이다.
③ Instability = 1/3 — Ce/Ca = 1/3을 그대로 답으로 쓴 경우인데, 분모는 Ca가 아니라 Ca + Ce이므로 틀렸다.
④ Instability = 1/4 — Ce = 1, Ca = 3을 대입한 정확한 값이다. 정답.

핵심 정리:
I = Ce / (Ca + Ce), 0에 가까울수록 안정(다른 패키지가 많이 의존, 변경이 어려움), 1에 가까울수록 불안정(자신이 많이 의존, 변경이 쉬움)하다.
화살표가 들어오면 Ca, 나가면 Ce로 세며, 분모는 항상 두 값을 더한 전체 결합 수라는 점이 최대 함정이다.
함께 출제되는 지표로 추상도 A = (추상 클래스 수 / 전체 클래스 수), 주계열 거리 D = |A + I - 1|이 있으며 D가 0에 가까울수록 바람직하다.
안정 의존성 원칙(SDP)은 더 안정적인 방향(I가 낮은 쪽)으로 의존하라는 규칙이다.
