정답: ② (2번)

해설:
Java의 추상 클래스 인스턴스화 제약과 참조 변수의 업캐스팅/다운캐스팅 규칙을 묻는 문항이다. 상속 계층은 AType(추상) ← BType ← CType 이다.

판정 규칙:
추상 클래스는 new로 직접 인스턴스를 생성할 수 없다.
상위 타입 참조변수에 하위 타입 객체를 대입하는 업캐스팅은 명시적 캐스트 없이 허용된다.
하위 타입 참조변수에 상위 타입 객체를 대입하는 것은 명시적 다운캐스트 없이는 컴파일 오류이며, 실제로 상위 타입 객체를 만든 경우 캐스트해도 런타임 오류가 난다.

각 항목 컴파일 여부:
가. AType a1 = new AType(); — AType은 abstract이므로 인스턴스 생성 불가. 컴파일 오류.
나. BType a2 = new BType(); — 동일 타입 대입. 정상.
다. AType a3 = new BType(); — BType은 AType의 하위 타입이므로 업캐스팅. 정상.
라. BType a4 = new AType(); — 추상 클래스 생성 자체가 불가하고 상위 타입을 하위 타입 변수에 대입하는 것도 불가. 컴파일 오류.
마. BType a5 = new CType(); — CType은 BType의 하위 타입이므로 업캐스팅. 정상.
바. CType a6 = new BType(); — 상위 타입 BType 객체를 하위 타입 CType 변수에 대입. 컴파일 오류.
컴파일되는 것은 나, 다, 마이다.

각 보기 분석:
① 가, 다 — 가는 추상 클래스 인스턴스화로 컴파일되지 않는다.
② 나, 다, 마 — 정상 대입 세 가지를 정확히 골랐다. 정답.
③ 다, 라, 마 — 라는 컴파일 오류이므로 포함될 수 없다.
④ 라, 마, 바 — 라와 바 모두 컴파일 오류이다.

핵심 정리:
추상 클래스와 인터페이스는 new로 직접 생성할 수 없고 구현체를 통해서만 인스턴스를 얻는다.
업캐스팅(하위 객체를 상위 변수에)은 항상 안전해 암묵적으로 허용, 다운캐스팅(상위 객체를 하위 변수에)은 명시적 캐스트가 필요하고 실제 객체 타입이 맞지 않으면 ClassCastException이 발생한다.
"변수 타입은 넓게, 객체 타입은 좁게"가 성립할 때만 컴파일된다고 기억하면 빠르게 판정할 수 있다.
