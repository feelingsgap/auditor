정답: ② (2번)

해설:
IFPUG 기능점수(Function Point) 분석에서 데이터 기능은 ILF(Internal Logical File)와 EIF(External Interface File)로 나뉜다. ILF는 해당 애플리케이션 경계 안에서 유지·관리(생성/갱신/삭제)되는 논리 데이터 그룹이고, EIF는 다른 애플리케이션이 유지·관리하며 본 시스템은 참조(조회)만 하는 논리 데이터 그룹이다.

식별 과정:
민원 신청 정보는 민원관리 시스템이 직접 저장하고 처리 상태를 갱신하며 수정까지 수행한다. 즉 유지·관리 대상이므로 ILF 1개이다.
인사시스템에 저장된 직원 정보는 인사시스템이 유지하고 본 시스템은 조회만 하므로 EIF 1개이다.
회계시스템의 예산 데이터 역시 회계시스템이 유지하고 조회만 하므로 EIF 1개이다.
따라서 ILF 1개, EIF 2개이다.

각 보기 분석:
① ILF 1개, EIF 1개 — 외부에서 참조하는 대상이 인사·회계 두 시스템이므로 EIF가 하나 부족하다.
② ILF 1개, EIF 2개 — 민원 정보를 유지하고 직원 정보·예산 데이터를 참조하는 구조와 정확히 일치한다. 정답.
③ ILF 1개, EIF 3개 — 외부 참조 논리 파일이 3개라는 근거가 지문에 없다.
④ ILF 2개, EIF 1개 — 민원 신청 정보와 처리 상태는 하나의 논리 데이터 그룹으로 보며 외부 참조는 2개이므로 맞지 않다.

핵심 정리:
ILF는 내가 유지·관리(CRUD)하는 논리 파일, EIF는 남이 유지하고 나는 읽기만 하는 논리 파일이다.
"저장한다·갱신한다·수정한다" 표현이 나오면 ILF, "조회하여 활용한다" 표현이 나오면 EIF로 판정한다.
데이터 기능(ILF/EIF)과 트랜잭션 기능(EI 입력, EO 가공 출력, EQ 단순 조회)을 혼동하지 않도록 주의한다.
