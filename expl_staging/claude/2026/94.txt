정답: ④ (4번)

해설:
보기의 세 설명(다익스트라 알고리즘 기반 링크 상태 라우팅, AS 내부용 IGP, 변화 시에만 멀티캐스트 갱신)은 모두 OSPF(Open Shortest Path First)의 특징이다. 동적 라우팅 프로토콜은 동작 범위(IGP/EGP)와 알고리즘(거리 벡터/링크 상태)의 두 축으로 분류하면 쉽게 정리된다.

각 보기 분석:
① RIP(Routing Information Protocol) — AS 내부에서 쓰이는 IGP인 것은 맞지만, 벨만-포드 기반의 거리 벡터(Distance Vector) 프로토콜이다. 홉 수를 메트릭으로 쓰고 최대 15홉으로 제한되며, 변화가 없어도 30초마다 전체 라우팅 테이블을 브로드캐스트해 대역폭 효율이 낮다. 알고리즘과 갱신 방식이 모두 보기와 다르므로 오답.
② ARP(Address Resolution Protocol) — IP 주소를 MAC 주소로 변환하는 주소 해석 프로토콜이며 라우팅 프로토콜이 아니다. 오답.
③ BGP(Border Gateway Protocol) — AS 간 경로를 교환하는 EGP이며, 경로 벡터(Path Vector) 방식으로 AS 경로 목록을 전달한다. AS 내부용이라는 조건과 어긋나므로 오답.
④ OSPF(Open Shortest Path First) — 각 라우터가 링크 상태 정보(LSA)를 플러딩해 전체 네트워크 토폴로지 지도(LSDB)를 동일하게 구성한 뒤, 다익스트라 최단 경로 알고리즘으로 자신을 루트로 하는 SPF 트리를 계산한다. AS 내부에서 동작하는 IGP이며, 토폴로지 변화가 있을 때만 LSA를 멀티캐스트(224.0.0.5, 224.0.0.6)로 전파해 대역폭 효율이 높다. 보기 세 항목과 모두 일치한다. 정답.

핵심 정리:
동작 범위 분류 — IGP(AS 내부): RIP, OSPF, IS-IS, EIGRP / EGP(AS 간): BGP.
알고리즘 분류 — 거리 벡터(벨만-포드): RIP, IGRP / 링크 상태(다익스트라): OSPF, IS-IS / 경로 벡터: BGP / 하이브리드: EIGRP(DUAL).
OSPF의 장점: 빠른 수렴, VLSM·CIDR 지원, 홉 수 제한 없음, 대역폭 기반 비용(cost) 메트릭, Area 분할을 통한 계층적 확장(모든 Area는 백본 Area 0에 연결).
거리 벡터는 "이웃에게만, 주기적으로, 전체 테이블을" 보내고 무한 계수(count-to-infinity) 문제가 있어 스플릿 호라이즌·홀드다운 타이머로 대응한다. 링크 상태는 "전체에게, 변화 시에만, 링크 정보를" 보낸다.
함정 포인트는 RIP과 OSPF 모두 IGP라는 점이다. "다익스트라", "링크 상태", "멀티캐스트 갱신" 중 하나라도 나오면 OSPF로 확정한다.
