정답: ① (1번)

해설:
메모리 계층 구조(Memory Hierarchy)를 설계하는 근본 이유를 묻는 문항이다. 메모리는 속도가 빠를수록 비트당 단가가 비싸고 용량을 크게 만들기 어렵다는 물리적 제약이 있다. 따라서 빠르고 비싼 소량의 메모리를 CPU 가까이 두고, 느리고 저렴한 대용량 메모리를 뒤에 배치해 "평균 접근 시간은 빠른 메모리에 가깝게, 평균 비용과 용량은 느린 메모리에 가깝게" 만드는 것이 목적이다. 이것이 성립하는 근거는 참조의 지역성(Locality of Reference)이다.

각 보기 분석:
① 속도가 빠르고 비싼 메모리와 느리지만 저렴한 메모리를 조합해 최적의 가성비를 얻기 위해 — 메모리 계층 구조의 정확한 설계 목적이다. 지역성 덕분에 자주 쓰는 소수의 데이터만 상위 계층에 두어도 대부분의 접근이 상위 계층에서 처리되어, 비용은 하위 계층 수준이면서 체감 속도는 상위 계층에 근접한다. 정답.
② 메인 메모리의 전력 소모 감소가 유일한 목적 — 전력 절감은 부수적 효과일 뿐이고 "유일한 목적"이라는 단정이 틀렸다. 오답.
③ 모든 데이터를 가장 빠른 CPU 레지스터에만 저장하기 위해 — 레지스터는 용량이 수십~수백 바이트 수준이라 물리적으로 불가능하며, 계층 구조는 오히려 데이터를 여러 계층에 나누어 배치한다. 오답.
④ 보조기억장치를 제거하고 캐시만 사용하기 위해 — 계층 구조는 보조기억장치를 최하위 계층으로 포함하는 개념이지 제거하는 것이 아니다. 오답.

핵심 정리:
계층 순서(빠르고 비쌈 → 느리고 쌈): 레지스터 → 캐시(L1/L2/L3) → 주기억장치(DRAM) → SSD/HDD → 백업 매체(테이프).
아래로 갈수록 용량은 커지고 비트당 가격과 접근 시간은 커진다. 계층 간 데이터 이동 단위도 커진다(워드 → 블록/라인 → 페이지 → 파일).
효과가 성립하는 전제는 지역성이다. 시간 지역성(최근 참조한 것을 다시 참조), 공간 지역성(인접 주소 참조), 순차 지역성(코드의 순차 실행).
평균 접근 시간 = 적중률 × 상위계층 접근시간 + (1 - 적중률) × 하위계층 접근시간.
함정 포인트는 "유일한", "모든", "제거" 같은 단정적 표현이다. 계층 구조는 트레이드오프를 절충하는 설계이지 어느 한쪽을 없애는 설계가 아니다.
