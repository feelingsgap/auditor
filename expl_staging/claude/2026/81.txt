정답: ④ (4번)

해설:
디지털 코드의 특성을 구분하는 문항이다. 핵심 키워드는 "인접한 값으로 변할 때 오직 하나의 비트만 변화"라는 단일 비트 변화(unit distance) 성질이다. 이 성질을 갖는 코드는 그레이 코드가 유일하다.

각 보기 분석:
① ASCII 코드 — 문자를 7비트(확장 8비트)로 표현하는 문자 인코딩 표준이다. 인접 문자 간 비트 변화 수는 일정하지 않으며 위치 제어용이 아니다. 오답.
② Excess-3 코드 — 8421 BCD에 3을 더한 자기보수(self-complementing) 코드로, 9의 보수를 비트 반전만으로 구할 수 있어 감산 연산에 유리하다. 단일 비트 변화 특성은 없으므로 오답.
③ 2진 코드(Pure Binary) — 가장 기본적인 가중치 코드지만 인접 값 사이에 여러 비트가 동시에 바뀐다. 예를 들어 0111(7) → 1000(8)은 4비트가 한꺼번에 변해, 스위치 전환 시점 차이로 순간적으로 엉뚱한 값이 읽히는 글리치가 발생한다. 오답.
④ 그레이 코드(Gray Code) — 인접한 두 수 사이에 정확히 1비트만 달라지도록 설계된 비가중치(non-weighted) 코드다. 0000 → 0001 → 0011 → 0010 → 0110처럼 진행하며, 로터리 엔코더 등 기계적 위치 제어와 데이터 전송에서 전이 오류를 줄이는 데 사용된다. 정답.

핵심 정리:
그레이 코드는 비가중치 코드이며 산술 연산에는 부적합하고 오직 위치 검출·오류 감소 용도로 쓰인다.
2진수 → 그레이 변환: 최상위 비트는 그대로 두고, 이후 비트는 인접한 두 2진 비트를 XOR한다. 예: 이진 0111 → 그레이 0100.
그레이 → 2진 변환: 최상위 비트는 그대로, 이후는 직전에 구한 2진 비트와 현재 그레이 비트를 XOR한다.
코드 유형 정리 — 가중치 코드: 8421 BCD, 2421, 5211 / 비가중치 코드: 그레이, Excess-3(자기보수) / 오류검출 코드: 패리티, 해밍, CRC.
함정 포인트는 Excess-3와 그레이 코드 모두 비가중치라는 점이다. "자기보수·감산 유리"면 Excess-3, "1비트만 변화·위치 제어"면 그레이 코드다.
