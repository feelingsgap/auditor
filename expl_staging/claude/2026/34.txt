정답: ③ (3번)

해설:
UML State Machine 다이어그램에서 entry/exit 액션과 복합 상태(Composite State)의 진입·이탈 순서를 정확히 적용해 변수 값을 추적하는 문항이다. 그림 구조는 다음과 같다. 초기 의사상태의 전이 효과가 /x = 1 이고, 복합 상태 A는 entry/x = x*2, exit/x = x-1을 가진다. A 내부에는 초기 의사상태에서 E1로 전이하는 상태 B가 있고 B는 entry/x = x+1, exit/x = x+2를 가지며, B에서 E2로 A의 최종 상태로 전이한다. A가 완료되면 상태 C로 넘어가고 C는 entry/x = x*2, exit/x = x-2를 가진다. 이후 E3로 상태 D(entry/x = x*2)로 간다.

값 추적 과정:
1) 초기 전이 효과 x = 1 → x = 1
2) 복합 상태 A 진입, A의 entry 실행 x = x*2 → x = 2
3) E1 발생, A 내부 초기 상태에서 B로 전이하며 B의 entry 실행 x = x+1 → x = 3
4) E2 발생, B에서 이탈하며 B의 exit 실행 x = x+2 → x = 5
5) A의 최종 상태 도달로 A 완료, A에서 이탈하며 A의 exit 실행 x = x-1 → x = 4
6) 완료 전이로 C 진입, C의 entry 실행 x = x*2 → x = 8
E3는 발생하지 않았으므로 최종 상태는 C이고 x = 8이다.

각 보기 분석:
① 3 — B의 entry까지만 반영한 값으로 E2 이후의 exit 액션들을 누락한 결과이다.
② 5 — B의 exit까지만 반영하고 복합 상태 A의 exit와 C의 entry를 빠뜨린 값이다.
③ 8 — B exit(+2), A exit(-1), C entry(*2)까지 모두 반영한 값으로 정확하다. 정답.
④ 10 — A의 exit(x-1)을 적용하지 않고 5를 두 배 한 값으로, 복합 상태 이탈 액션을 놓친 오답이다.

핵심 정리:
액션 실행 순서는 이탈 시 내부(하위) 상태 exit → 외부(복합) 상태 exit, 진입 시 외부 상태 entry → 내부 상태 entry 순이다.
복합 상태의 내부 최종 상태에 도달하면 완료 전이(completion transition)가 트리거되어 별도 이벤트 없이 다음 상태로 넘어간다.
entry/exit/do 액션과 전이 효과(effect)를 빠짐없이 순서대로 적용하는 것이 이런 유형의 유일한 함정 포인트이다.
